# Suggested Commands

## Development & Execution
- Run bot: `python main.py`
- Run test suite: `python -m unittest discover tests`
- Run single test file: `python -m unittest tests/test_all.py`

## Indexing & Code Intelligence
- Rebuild codegraph index: `codegraph index .`
- Query codegraph: `codegraph query "<search>"`
- Explore flow: `codegraph explore "<symbol or flow>"`
